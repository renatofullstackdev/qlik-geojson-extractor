Privacidade

      
A extensão solicita acesso somente ao host Qlik escolhido pelo usuário, em tempo de execução. O manifesto declara hosts HTTP/HTTPS apenas como permissões opcionais; nenhum host é concedido automaticamente na instalação. A extensão não envia dados a servidores externos e armazena somente configurações, nunca o GeoJSON extraído.
